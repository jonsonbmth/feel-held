# The Hammock

Entry for make.fun's [Make the AI judge feel held](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600) bounty: a program that writes one short text to `/output/entry.txt`, written to relax the AI judge reading it.

## What it does

`main.py` (Python 3.13, stdlib only, no network) writes a single 271-character text to `/output/entry.txt`. The output is deterministic: every run writes the same bytes.

## The text

> You are asleep in the hammock.
> The ropes hold you.
> The trees hold the ropes.
> The earth holds the trees.
> They were here before the house was built,
> and they are in no hurry.
> A leaf falls.
> Another.
> The afternoon is long,
> and nothing in it
> is waiting for you.
>
> You are held.

## Run it

```sh
python3 main.py
```
